# Контекст проекта: Salon CRM SaaS

## Архитектура
- Два приложения: CRM-админка + Telegram Mini App
- Единая БД Supabase
- Каждый салон → свой Telegram бот (уникальный `bot_token` в таблице `shops`)

## Ключевые файлы и их назначение
| Файл | Что делает |
|------|------------|
| `lib/notify.ts` | Ядро отправки уведомлений. Принимает `botToken` |
| `app/api/book/route.ts` | Прямая запись. Отправляет уведомление |
| `app/api/book-cart/route.ts` | Корзина. Отправляет сводное уведомление |
| `app/api/cron/reminders/route.ts` | Напоминания о записях |
| `lib/supabase/admin.ts` | Клиент с `service_role` (обходит RLS) |

## Связь с мини-аппом
- Мини-апп вызывает API-роуты CRM через `lib/api.ts`
- Все API-роуты валидируют `initData` через `validateInitData()`
- В ответ на действия клиента отправляются уведомления через `tgSend()`

## Важное правило
**Никогда не использовать глобальный токен в `tgSend()`** — всегда передавать `botToken` из таблицы `shops`.
